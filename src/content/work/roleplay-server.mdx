## What it was

This is a personal project, and it is where my coding started. I ran a British-themed roleplay server with a co-owner, on FiveM, a platform for running your own modded multiplayer servers for GTA V. We were both developers. The theme meant British emergency services, food and drink, cars and so on. I was working in retail and team-leading roles at the time.

## How it started

I was a player first, on someone else's server. I became friends with its owner, and I started by making custom vehicles for it.

That server shut down because the running costs were too high. So I started my own, and I learned Lua as I went. We built it from a base, so it was live quickly, and we had a test server where we did the coding.

## What I built

I began by fixing bugs in scripts that already existed, and by changing them to fit the theme of our server. As my knowledge and confidence grew, I started writing scripts of my own.

My first fully custom Lua script was a forklift worker job. Pallets spawn in, the player picks them up and delivers them to a location, and they are rewarded on every delivery. It is a small job, but it was the first one I wrote from nothing.

The server ran on the ESX framework, with a large MySQL database holding all of the player data. My co-owner could code too, and helped with bug fixes. Mostly we each worked on our own things.

## Running the community

The community grew past 1,000 members, and at its peak the server was full at 64 players every night.

At that size we had a full staff team, with a hierarchy running from moderators up to staff managers. Each role had different permissions, both on the game server and on Discord.

## What was hard

Cheaters were always something to watch. Cheat tools existed for ESX, and some of them let a player give themselves player-owned vehicles, money and the like.

My co-owner and I built a custom anticheat, and I wrote most of it, including the detection system. The cheat menus worked by calling certain functions in the framework. We rewrote those functions so they could spot a call that should not happen, and so catch the cheater.

Performance needed the same attention, on the server and in the scripts running on each player's own machine. We used developer tools to look at latency and at how much each script was using.

## How it ended

My son was born, and I no longer had the time to run the server. I stepped away, and it closed down shortly after.

## What it led to

There was no single moment where it clicked. I was enjoying building things for the server, and then I realised I could do this as a job.

My interest in coding grew. I searched for entry-level jobs and found an apprenticeship, and I started as an apprentice at Digitwell Solutions in 2022. The server got me to where I am today, working as a software developer.
