About this site

How it is built

This is a static site built with Astro. I build it on my own machine and publish the built files to GitHub Pages.

The checks also run on my machine. The site has no analytics and no cookie banner, and it loads no third-party scripts.

How AI is involved

I build this site with Claude Code, Anthropic's coding assistant. I direct the work, review the changes and decide what is published.

Claude Code wrote the code for this site. I chose what to build, judged the designs and reviewed what came back.

The facts about my career come from me. Claude Code is told not to invent details to fill a gap.

Activity

The setup is public

The instructions Claude Code follows for this site are in the public repository on GitHub. They are a CLAUDE.md file, plus written rules and skills in the .claude folder.
